netl

Share files publicly via Netlify. Each call creates a fresh site, returns a public URL, and logs the URL locally so you can list past shares. Use it when ggc + gistpreview can't render your page (typically: native <script type="module"> imports).

01 Setup (one time)

$ npm install -g netlify-cli
$ netlify login

That's it. Future netl calls deploy into your Netlify account.

02 Usage

CommandWhat it does
netl file.html Single HTML — uploaded as index.html, root URL serves it directly.
netl a.html b.html data.json Multi-file — each by basename, with an auto-generated index.html linking them.
netl --list Print history file, newest first.
netl --list workspaces Filter history (case-insensitive substring match).
netl --help Show help.

03 What you get

  • Public URL — anyone can hit it (https://netl-share-<6hex>.netlify.app).
  • Stable — each netl call creates a new site. URLs don't get overwritten by future deploys.
  • Listable two ways — netl --list reads the local history file (~/.netl-history); netlify sites:list enumerates everything in your Netlify account.
  • No transformation — files upload as-is. ESM imports work, native modules work, anything modern browsers handle works.

04 Environment & history

env vars

Override behavior at call time.

NETL_NO_HISTORY=1 — skip writing this deploy to the history file.

NETL_HISTORY_FILE=path — use a different history file (default: ~/.netl-history).

history format

Tab-separated, one line per success.

# timestamp	url	files
2026-04-30T04:37:20Z	https://netl-share-ec3c82.netlify.app	page.html

UTC ISO 8601 timestamp, public URL, file paths joined by , . Failed deploys are not logged.

05 How it works

  1. Copies your file(s) into a temp directory. Single HTML becomes index.html; multi-file gets each by basename plus an auto-generated index.
  2. Runs netlify deploy from inside the temp directory. This sidesteps any ambient .netlify/ folder in your CWD that might link to a site you don't own.
  3. Site name is netl-share-<6hex>. The --site-name flag implies --create-site, so each call mints a fresh site rather than overwriting an existing one.
  4. Parses the JSON response, prints the production URL on stdout, and appends a line to ~/.netl-history.

06 Companion: ggc

ggc does the same idea but via GitHub gists + gistpreview.github.io. Use ggc when the file works on gistpreview (most CDN-script HTML); use netl when it doesn't (ESM imports, native modules, anything gistpreview's iframe loader breaks).

Same general pattern in both: returns a URL, no manual setup beyond the one-time install.

07 Troubleshooting

401 unauthorized

Stale site linkage in CWD.

Your CWD has a .netlify/ folder linked to a site you don't own. The script normally avoids this by cd-ing into a fresh temp directory before deploying. If you see this anyway, check that netlify --version is current.

daily limit reached

You're not logged in.

Anonymous deploys are capped at ~5/day. Run netlify login to remove the cap; future deploys go to your account and are listable via netlify sites:list.
