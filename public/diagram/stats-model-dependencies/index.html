How Native Queries Reference Models

Template tag syntax. Native SQL queries reference models via {{#4523-account}} — a slugified form of {{#<card-id>-<card-name>}}. When source replacement runs, it rewrites the SQL text and template-tags map to point to the new card ID.

Parameter mappings. Dashboard cards bind filters to model columns via field refs like ["dimension",["field",572280,null],{"stage-number":0}]. These also need updating when the source model changes, because field IDs may differ between the old and new source.

Source Replacement: The Challenge

Replacing the Account model means automatically rewriting 2,025 entities: updating source-card refs in 1,909 MBQL queries, rewriting {{#4523}} in 89 native SQL strings, updating template-tags maps, fixing field refs in 25 dashboard parameter mappings, and updating 2 transform source queries.

The 946 intermediary cards that are both dependent on Account and depended upon by other cards create a 3-level-deep cascade. Field ref upgrades must propagate through the full transitive closure before source swaps execute.

The acceptance test models this graph in miniature: old model → {2 MBQL children, 1 native child, 1 transform} → {2 grandchildren}. All 9 assertions pass.
