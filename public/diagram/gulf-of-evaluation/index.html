What I expect to see

After performing an action, I look at the system's response to evaluate: did it work? Is the state what I intended?

The Metabase Example

Selecting a group in the People admin page

1
User opens dropdown

Sees three options listed clearly

All Users   Administrators   Data Analysts
2
User selects "All Users"

Clear, intentional action. Mental model: "this user is in the All Users group."

3
System processes correctly

Internally assigns the user to the default permissions group. No error.

4
Table shows "Default"

The user evaluates: "Wait - I didn't pick 'Default'. What is that? Did something go wrong?"

Default
Principles Violated
Feedback

Confirm in the user's terms

Good feedback echoes the user's action. Showing "Default" after selecting "All Users" is a non-sequitur.

Consistency

Same concept, same name

Using two names for one thing forces users to maintain a mental translation table. That's cognitive overhead for nothing.

Conceptual Model

Don't leak internals

"Default" is the system's name. "All Users" is what it means. The user shouldn't need to know the implementation.

The Fix

Use the same label everywhere

The dropdown already got it right. "All Users" describes what the group is. "Default" describes how it was implemented. Match the table to the dropdown.

Before
Dropdown: All Users but then... Table: Default
->
After
Dropdown: All Users and... Table: All Users
"The best designs make the system state visible and interpretable without requiring the user to maintain a mental translation table."
- Don Norman, The Design of Everyday Things
