Convert Model to Transform

/api/ee/replacement — async 3-phase conversion pipeline

Converts a Metabase model into a transform. Creates a transform from the model's query, executes it to materialize a physical table, then replaces all usages of the model with the new table. The operation is async — you get back a run_id and poll for progress across 3 independent phases.
1 — Endpoints
POST /api/ee/replacement/convert-card-to-transform
Start a model-to-transform conversion. Requires superuser auth + :dependencies feature.
Request body
{ "card_id": 123 }
Response 202
{ "run_id": 7 }
400 Card exists but is not a model
404 Card not found
409 Another run already active
403 Not a superuser
402 Feature not enabled
GET /api/ee/replacement/runs
List all runs (both replace and convert). Optional query param is-active=true to filter.
Query params
?is-active=true (optional)
Response 200
[ { ...run object }, ... ]
GET /api/ee/replacement/runs/:id
Get a single run by ID. Returns the full run object including all phase progress fields. Existing endpoint, unchanged.
POST /api/ee/replacement/runs/:id/cancel
Cancel an active run. Works for both replace and convert runs. Each phase checks for cancellation on every progress advance.
2 — 3-Phase Async Flow
Phase 1
Transform
transform_progress
Creates a transform from the model's query and executes it. Materializes data into a physical table in the transforms schema. Includes syncing the output table into Metabase metadata.
1.0
Phase 2
Sync
sync_progress
Confirms the output table exists in Metabase metadata and records its table ID on the run. Updates target_entity_type to "table" and target_entity_id to the new table's ID.
1.0
Phase 3
Replacement
replacement_progress
Finds all entities that depend on the model (cards, transforms, dashboards) and rewrites their queries to reference the new table. Same logic as POST /replace-source.
1.0
Each phase tracks progress independently as a 0→1 float written to its own DB column. The legacy progress field is always 0.0 for convert runs — use the phase-specific fields instead.

Start
POST /convert-card-to-transform
{ "card_id": 123 }
202 → { "run_id": 7 }
Poll 1
GET /runs/7 → { "status": "started", "transform_progress": 0.5, "sync_progress": null, "replacement_progress": null }
Poll 2
GET /runs/7 → { "status": "started", "transform_progress": 1.0, "sync_progress": 1.0, "replacement_progress": 0.3 }
Done
GET /runs/7 → { "status": "succeeded", "is_active": null, "transform_progress": 1.0, "sync_progress": 1.0, "replacement_progress": 1.0, "target_entity_type": "table", "target_entity_id": 456, "end_time": "2026-03-11T12:05:00Z" }
4 — Run Object Shape
id Run identifier int
status Current state string
is_active true while running bool|null
run_type replace or convert string
source_entity_type card or table string
source_entity_id Source ID int
target_entity_type Updated mid-run string
target_entity_id Updated mid-run int
transform_progress Phase 1 float|null
sync_progress Phase 2 float|null
replacement_progress Phase 3 float|null
progress Legacy (replace only) float|null
message Error/status message string|null
user_id Who started it int|null
start_time When it started timestamp
end_time When it finished ts|null
Target fields update mid-run. target_entity_type and target_entity_id start as the source card (placeholder) and are updated to "table" + the actual table ID during Phase 2 once the output table is synced.

is_active is true only during started. It is set to null (not false) for all terminal states, which allows the unique constraint to enforce at most one active run.
6 — Mutex Behavior
Replace Run
POST /replace-source
run_type: "replace"
🔒
UNIQUE(is_active)
Only one row
can be true
Convert Run
POST /convert-card-to-transform
run_type: "convert_to_transform"
Both run types share the same is_active unique constraint on source_replacement_run. A replace blocks a convert, a convert blocks a replace, and two of either kind block each other. Second attempt returns 409. Timeout: runs active >30 minutes are automatically timed out by a background Quartz job.
