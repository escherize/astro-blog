Analytics Value Capture Flow

embedding-mw → wrap-current-user-info → bind-current-user → include-sdk-info

Three independent values - embedding_route, embedding_client, and auth_method - are captured at different points in the Ring middleware chain and stored on every view_log and query_execution row. A fourth value, surface, is computed downstream in SQL views from embedding_route and embedding_client.

Route fallback in bind-current-user. When no session or API key authenticates the request, auth_method falls back to the route surface. The map {"guest-embed" "guest"} renames the route value so auth_method reads "guest" rather than duplicating embedding_route's "guest-embed". Other routes ("public", "metabot", "agent-api") pass through unchanged.
